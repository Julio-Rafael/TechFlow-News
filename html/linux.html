Ubuntu 26.10 adotará Linux Kernel 7.3

O desenvolvimento do Ubuntu 26.10 teve uma mudança importante nesta semana: a próxima versão da distribuição passou a utilizar o Linux Kernel 7.3, em vez do Kernel 7.2 que estava previsto anteriormente. A versão também está avançando para a próxima etapa de testes antes do lançamento.

Clonezilla Live recebe atualização

O Clonezilla Live lançou a versão 3.3.3-37 com suporte a HTTP Boot, repositórios LUKS2, melhorias para telas de alta resolução e atualização do kernel Linux para a versão 7.1.13-1. A atualização também inclui melhorias nas ferramentas de clonagem de discos.

Ubuntu conclui migração de ferramentas para Rust

O Ubuntu 26.10 concluiu a migração dos comandos cp, mv e rm para implementações do projeto uutils Coreutils, desenvolvido em Rust. A mudança faz parte do esforço para utilizar uma linguagem com foco em segurança de memória em componentes do sistema operacional.
