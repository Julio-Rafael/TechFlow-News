Ubuntu conclui migração de ferramentas para Rust

O Ubuntu 26.10 concluiu a migração dos comandos cp, mv e rm para implementações do projeto uutils Coreutils, desenvolvido em Rust. A mudança faz parte do esforço para utilizar uma linguagem com foco em segurança de memória em componentes do sistema operacional.

Ubuntu 26.10 conclui migração do Coreutils para implementações em Rust

Enquanto o Ubuntu Linux vem fazendo uso do projeto Rust Coreutils no ano passado desde o Ubuntu 25.10 como uma alternativa ao GNU Coreutils e parte de seu esforço para obter mais componentes do sistema implementados na linguagem de programação Rust focada em segurança de memória, o Ubuntu 26.10 finalmente completa a transição com os comandos cp, mv e rm agora provenientes do Rust Coreutils.

O Ubuntu 26.04 LTS e o Ubuntu 25.10 não haviam feito uso das versões Rust Coreutils de cp, mv e rm devido a problemas de compatibilidade. Mas agora tudo está bem em uutils upstream para permitir que a transição seja concluída.

O rascunho do Ubuntu 26.10 lançar notas foram atualizados recentemente para refletir a conclusão "100%" sobre sua transição Rust Coreutils.

A versão beta do Ubuntu 26.10 está chegando neste mês, enquanto a versão estável do Ubuntu 26.10 é mostrada em 15 de outubro.
