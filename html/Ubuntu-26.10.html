Ubuntu 26.10 muda os planos e adotará o Linux Kernel 7.3

O desenvolvimento do Ubuntu 26.10 teve uma mudança importante nesta semana: a próxima versão da distribuição passou a utilizar o Linux Kernel 7.3, em vez do Kernel 7.2 que estava previsto anteriormente. A versão também está avançando para a próxima etapa de testes antes do lançamento.

Ubuntu 26.10 Alterna Para O Kernel Linux 7.3

Em maio, a equipe do kernel da Canonical anunciou Ubuntu 26.10 seria lançado com Linux 7.2 com base em seu alinhamento de lançamento na época para o envio da última versão principal do kernel upstream nesta atualização de outubro do Ubuntu Linux. Mas venha hoje com os e-mails do leitor do Phoronix e em sudo apt dist-upgrade em algumas das minhas máquinas de teste, o Linux 7.3 agora está presente como uma surpresa muito maravilhosa.

O Linux 7.3 estará alimentando o Ubuntu 26.10 em vez do Linux 7.2. Acontece que havia um post Discurso Eu faltei no início deste mês, onde eles anunciaram um realinhamento para o Linux 7.3. Devido a nenhum atraso para o Linux 7.1 e Linux 7.2, a equipe de kernel da Canonical está confortável o suficiente com o Linux 7.3, em vez do Linux 7.2.

  • "Seguindo nosso anúncio anterior, a Equipe Canonical Kernel reavaliou nosso kernel de destino para a versão do Ubuntu 26.10 (Stonking Stingray).

  • Graças ao cronograma de desenvolvimento do Linux upstream, que não enfrentou atrasos durante os ciclos de lançamento 7.1 e 7.2 e já viu o lançamento de 7.3-rc1, estamos animados em compartilhar que estamos intensificando nosso alvo: Ubuntu 26.10 agora vai direcionar o kernel Linux 7.3 em vez de 7.2.

  • Esta atualização nos mantém alinhados com os mais recentes recursos upstream, particularmente para o mais recente suporte de hardware, permanecendo no caminho certo para nossos próximos marcos de lançamento.

  • A equipe está atualmente trabalhando em habilitar todos os recursos específicos do Ubuntu em cima do kernel upstream 7.3-rc1; ele estará disponível em breve no bolso proposto para testes antecipados."

Isso é ótimo considerando todas as novidades e melhorias no Linux 7.3.O.

O kernel do Linux 7.3 estava no arquivo proposto para o Stonking Stingray, mas agora está sendo lançado para o arquivo "Stonking" do Ubuntu 26.10 antes do lançamento beta da próxima semana.

O Ubuntu 26.10 está programado para ser lançado em 15 de outubro, enquanto o kernel freeze está em 1 de outubro. Assim, para as ISOs oficiais antes das atualizações de lançamento estáveis, ele terminará em um estado de kernel de pré-lançamento. Se o Linux 7.3 lançar no prazo, ele será lançado em 18 de outubro, caso contrário, se um candidato a lançamento adicional for necessário, ele será adiado para 25 de outubro. Com esta não sendo uma versão do Ubuntu LTS, eles estão buscando vigorosamente a versão mais recente do kernel upstream.
