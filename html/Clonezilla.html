Clonezilla Live recebe atualização

O Clonezilla Live lançou a versão 3.3.3-37 com suporte a HTTP Boot, repositórios LUKS2, melhorias para telas de alta resolução e atualização do kernel Linux para a versão 7.1.13-1. A atualização também inclui melhorias nas ferramentas de clonagem de discos.

Clonezilla Live 3.3.3-37 adiciona suporte a HTTP Boot e LUKS2

O Clonezilla Live 3.3.3-37 foi lançado como a versão mais recente do popular utilitário de clonagem e geração de imagens de disco de código aberto, trazendo um kernel Linux atualizado, suporte a inicialização HTTP, suporte a repositório LUKS2 e diversas melhorias para clonagem direta de disco.

A nova versão é baseada nos repositórios Debian Sid de 13 de setembro de 2026. O kernel Linux foi atualizado para a versão 7.1.13-1. O Partclone, um componente essencial para geração de imagens de partição, também foi atualizado para a versão 0.3.50, que corrige um problema relacionado ao Btrfs.

Uma adição notável no Clonezilla Live 3.3.3-37 é o suporte expandido à inicialização de rede no Clonezilla Lite Server. Além da opção PXE Boot existente, os administradores agora podem usar clientes HTTP Boot, incluindo suporte ao Secure Boot ao inicializar via HTTP.

A versão também introduz suporte para repositórios LUKS2, expandindo as opções de armazenamento criptografado. Vários componentes de rede mais antigos foram limpos, substituindo comandos obsoletos do net-tools por equivalentes do iproute2 e removendo o código relacionado ao dhclient em favor do dhcpcd.

Os usuários que executam o Clonezilla em monitores modernos de alta resolução devem ver uma melhoria. O GRUB agora usa resoluções preferenciais de 1920×1080 e 1024×768, com uma opção automática e um fallback de 1024×768.

O processo de restauração do Clonezilla também foi otimizado. Ao restaurar uma imagem para o mesmo disco ou layout de partição, o software pode ignorar a conversão desnecessária de partição-imagem.

Além disso, o cnvt-ocsiso-qcow2 O utilitário foi reformulado com modos de empacotamento VHD e ISO separados, prefixos configuráveis e uma correção para pânicos do kernel ao inicializar imagens VHD convertidas.

Vários bugs foram corrigidos nesta versão. Entre eles está uma solução para um LVM sistema.dispositivos problema de bloqueio que afeta o RHEL 10 e o AlmaLinux 10 ou mais recente. O Clonezilla também corrige um problema em que o tamanho ou o sistema de arquivos não podiam ser detectados em um disco vazio contendo um sistema de arquivos.

A versão também corrige um problema em que a interface de texto para escolher ações de desligamento, reinicialização ou comando não apareceu depois que uma operação de clonagem foi concluída. Além disso, a interface Partclone ncurses agora está habilitada para clonagem direta de dispositivo para dispositivo.

Outras mudanças incluem melhor manuseio de relógios de hardware de horário local, ajustes relacionados ao bloqueio do Secure Boot, uma correção para detecção automática de fontes de console em sistemas Full HD não KMS e a adição dos pacotes netpbm e fonts-unifont ao ambiente ao vivo.
