# TechFlow-News

O TechFlow News é um site de notícias sobre tecnologia,
desenvolvido como projeto acadêmico para a faculdade
de Ciência da Computação.

O projeto tem como objetivo aplicar os conhecimentos
adquiridos nas aulas de HTML5, utilizando estrutura
semântica, navegação entre páginas e diferentes
elementos HTML.

O site aborda temas relacionados ao mundo da tecnologia,
como Inteligência Artificial, Cibersegurança,Games e Linux.

## 🎯 Objetivo

Desenvolver um site de notícias utilizando HTML5 puro,
colocando em prática os seguintes conhecimentos:

- Estrutura básica do HTML5;
- Tags semânticas;
- Criação de páginas interligadas;
- Formulários HTML;
- Inserção de áudio e vídeo;
- Utilização de imagens;
- Tags de marcação avançada;
- Organização de arquivos e pastas.
